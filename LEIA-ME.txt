CONTROLE FINANCEIRO - DESENVOLVIMENTO WEB I

Sistema Web completo (Cliente + Servidor Node.js/Express + Banco SQLite).

COMO EXECUTAR
1. Abra um terminal nesta pasta.
2. Caso ainda não tenha instalado as dependências, execute:
   npm install
3. Inicie o servidor:
   node server.js
4. Acesse http://localhost:3000 no navegador.
5. Para encerrar o servidor, pressione Ctrl+C no terminal.

COMO USAR
- Cadastro: crie um usuário com nome, e-mail e senha (mínimo de 6 caracteres).
- Login: entre com o e-mail e a senha cadastrados.
- Transações: adicione, edite, filtre por tipo ou exclua receitas e despesas.
- Dashboard: confira saldo, totais e as cinco transações mais recentes por data.

ARQUIVOS PRINCIPAIS
- server.js: servidor Express, middlewares e entrega das páginas.
- database/db.js: conexão com SQLite (financeiro.db) e criação das tabelas usuarios e transacoes.
- routes/usuarios.js: rotas de cadastro (POST /api/usuarios) e login (POST /api/login).
- routes/transacoes.js: rotas CRUD de transações (GET, POST, PUT, DELETE /api/transacoes).
- index.html, cadastro.html, dashboard.html, transacoes.html: páginas HTML semânticas.
- css/estilo.css: layout responsivo mobile-first com CSS Grid, Flexbox e media queries.
- js/script.js: manipulação do DOM, validações e chamadas fetch para a API.
